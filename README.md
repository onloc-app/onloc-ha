# Onloc - Home Assistant Integration
This integration for Home Assistant lets you display your devices from an Onloc server in Home Assistant. This data can be useful to trigger automations.

The documentation can be found online on the [official Onloc website](https://onloc.app/docs/category/home-assistant) or here on GitHub in the [website's repo](https://github.com/onloc-app/onloc-website/tree/main/docs/home-assistant).
